# FXGuard AI Project Summary

FXGuard AI is a full-stack experimental exchange-rate risk classification and payment-planning prototype for Rwanda-based importers. A user selects an invoice payment date from tomorrow through 100 days ahead, and a horizon-aware model classifies depreciation pressure for USD/RWF, EUR/RWF, or KES/RWF as Low, Medium, or High. It does not prevent depreciation, hedge exposure, or recommend a financial transaction.

The current prototype includes:

1. Multi-currency payment checks for USD, EUR, and KES
2. Three horizon-aware classifiers trained on every 1–100-day calendar period
3. Approximate uncalibrated model scores, recent-rate drivers, RWF cost estimates, and payment considerations
4. Dashboard rate history and data-freshness reporting
5. Excel result exports
6. Optional one-time-code accounts with user-owned cloud history
7. Check deletion, account data export, account deletion, consent, privacy, and terms flows
8. Guest device history and participant feedback collection
9. A FastAPI backend and responsive JavaScript frontend deployed separately on Render

The bundled histories come exclusively from official BNR Excel exports in `data/raw/`. Model features use official posting rows only, so forward-filled weekends are excluded from training. Model selection compares Logistic Regression, Random Forest, and XGBoost with forward-only rolling-origin backtesting, horizon-specific training-only thresholds, outcome-date purge gaps of up to 100 days, a most-frequent baseline, and a final chronological holdout. None of the three flexible classifiers passes the project's provisional reliability gate, so live results are explicitly experimental.

The active data and models are generated by `scripts/sync_multicurrency_rates.py` and `scripts/train_flexible_horizon_models.py`. The fixed 7/14-day scripts and notebooks are preserved as earlier research iterations and are not loaded by the active API.
