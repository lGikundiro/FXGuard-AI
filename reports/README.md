# FXGuard AI Report Index

## Current multicurrency evidence

These files describe the active USD/RWF, EUR/RWF, and KES/RWF application:

| File | Purpose |
|---|---|
| `multicurrency_model_evaluation.md` | Generated fold-by-fold backtest and final-holdout results for all six currency/horizon tasks |
| `testing_and_backtesting_report.md` | Plain-language technical report, limitations, report-ready conclusion, and presentation material |
| `../backend/models/multicurrency_model_metadata.json` | Machine-readable training, backtesting, selection, and holdout metadata |
| `../tests/test_multicurrency_backtesting.py` | Automated tests for forward-only folds, purge gaps, aggregation, and holdout isolation |

The current results are regenerated by:

```text
python scripts/sync_multicurrency_rates.py
python scripts/train_multicurrency_models.py
python -m unittest discover -s tests -p "test_*.py" -v
```

## Preserved legacy material

The following files belong to the original USD/RWF-only research workflow and are retained for reproducibility:

| File | Status |
|---|---|
| `model_evaluation.md` | Legacy USD-only model evaluation generated by `scripts/train_models.py` |
| `dataset_summary.md` and `dataset_summary.json` | Legacy USD-only prepared-dataset summary |
| `source_report_text.txt` | Extracted text from the older Word technical report |
| `../backend/models/model_metadata.json` | Legacy USD-only model metadata |
| `../backend/models/risk_model_7d.pkl` and `risk_model_14d.pkl` | Legacy USD-only model files |
| `../notebooks/` | Guided original USD/RWF workflow |

These legacy files are not loaded by the active API. The active API loads currency-specific files named `risk_model_<CURRENCY>_<HORIZON>d.pkl` and reads `multicurrency_model_metadata.json`.
